## 3. 场景实测（真实运行）

### 3.1 正常输入：直线行走日志

| 项 | 内容 |
|---|---|
| 命令 | python scripts/audit.py full --project examples/demo_robot --log examples/demo_robot/logs/run_straight.csv --out audit-out/doc-straight |
| 输入 | 5 个工程文件（URDF / YAML×2 / launch / cpp）+ 200 行 CSV（含 truth_x、truth_y） |
| 预期 | 发现轮半径 0.05 与 URDF 0.0508 冲突；由真值反推出约 1.6% 尺度误差；收敛到 0.0508 |
| 实际 | 严重 1 / 高 7 / 中 2 / 低 1 / 信息 5，退出码 **2** |
| 关键结论 | S01 相对差 1.575%；R01 真值 0.995 m / 里程计 0.9793 m = 1.6%；C01 根因收敛为 0.0508，补丁 3 处（yaml 两处 + cpp 一处）；S02 单位冲突 1000 倍 |
| 判定 | 通过。反推值与静态证据独立吻合，说明整条链路（日志 → 尺度 → 静态比对 → 补丁）成立 |

### 3.2 正常输入：原地转向日志

| 项 | 内容 |
|---|---|
| 命令 | 同上，--log 换成 run_turn.csv |
| 输入 | 250 行 CSV（含 truth_yaw） |
| 预期 | 发现轮距 0.30 与 joint origin 几何 0.32 冲突；反推转角尺度 |
| 实际 | R02 真值 2.4 rad / 里程计 2.5599 rad = **-6.25%**；S04 声明 0.3 m / 几何 0.32 m；C02 收敛为 0.32，补丁 2 处，退出码 **2** |
| 判定 | 通过 |

### 3.3 无真值输入：PID 记录

| 项 | 内容 |
|---|---|
| 命令 | 同上，--log 换成 run_pid.csv |
| 输入 | 225 行 CSV，没有 truth 列 |
| 预期 | 识别抖动 / 死区 / 限幅 / 超调；同时拒绝给出绝对尺度结论 |
| 实际 | R03 周期抖动 **113%**（中位 20 ms，最大 51.5 ms）；R07 死区 **0.66 s**；R05 限幅 **20.1%**；R06 超调 **16.7%**、穿越 6 次；R04 延迟 **80 ms**；R01 与 R02 均为 unverifiable 且不含偏差百分比；无 C 类结论 |
| 判定 | 通过（含“拒绝下结论”的反向验证） |
