# 通用化与 Web App：从差速底盘到任意轮系 + 3D 模型

> 这份文档记录第二阶段的扩展：把"只认差速底盘"变成"给模型 + 给现实参数就能验证"，
> 并加了一个零依赖的本地 Web App。所有数字都来自本仓库代码的真实运行。

---

## 1. 为什么要扩展

第一版只覆盖差速底盘，因为那是访谈里用户的实际场景。但同样的"仿真对、实物不对"在
阿克曼车、麦轮平台、四轮滑移上一样存在，而且第一版有两个盲区：

1. **只认 URDF**。很多人手里是 MuJoCo 的 MJCF、Gazebo 的 SDF，或者只画了 3D 模型还没做仿真；
2. **只能校验已经写进文件的参数**，回答不了"模型里这个质量对不对""这条指令这个底盘做不做得到"。

第二版补的正是这两块，而且坚持同一条底线：**结论必须有据可查，判不了就写判不了**。

## 3. 一个公式覆盖五种底盘

轮子在车体坐标系里的位置是 (x, y)，半径 r，滚动方向角 α，滚子角 γ。
设 d = α + γ，则该轮贡献一行雅可比：

~~~
ω_i = (1/r) · [ cos d ,  sin d ,  −y·cos d + x·sin d ] · (vx, vy, ω)
~~~

- **差速**：两轮 γ=0、α=0 → ω = (vx ∓ b·ω)/r，即教科书公式；
- **麦轮**：γ=±45° → ω = (1/r)·0.707·(vx ∓ vy ∓ (a+b)·ω)；
- **全向轮**：γ=90°；
- **滑移转向**：四个普通轮，靠轮胎侧向变形转弯（工具按"不可侧滑"保守处理，会提示打滑风险）；
- **阿克曼**：可转向轮把 α 当作待求的转向角。

只有**普通轮（γ=0）**才额外贡献一条"不可侧滑"约束：

~~~
−sin d ·(vx − ω·y) + cos d ·(vy + ω·x) = 0
~~~

这条约束的残差就是"这条指令这个底盘做不做得到"的量化答案。

### 实测

| 场景 | 结果 |
|---|---|
| 麦轮（γ=±45°）命令 vx=0, vy=0.2 | 可行；四轮 ω = ±1.886 rad/s（= 0.2·cos45°/0.075） |
| 同一模型把 γ 写成 0 | **M02 HIGH**：残留侧滑 0.200 m/s，"这部分运动不会发生" |
| 阿克曼 1.5 m/s + 0.4 rad/s | 车身原点需 0.210 m/s 侧向速度（M11）；内轮 18.43°、外轮 13.57°，与 atan(L/(R∓t/2)) 解析值一致 |

## 4. 准静态动力学：够不够力

- 需求牵引力：`F = m·a + μ_roll·m·g + ½ρCdAv²`，按 `J^T f = F` 的最小范数解分配到各轮；
- 附着极限：`|f_i| ≤ μ·N_i`，超出即 M04，并给出超出倍数；
- 电机能力：按直流电机线性特性 `τ_max(ω) = τ_stall·(1 − ω/ω_noload)`，超出即 M05；
- 轮速上限：`|ω_i| > ω_max` → M03。

## 5. 3D 模型：质量与惯量能不能对上

`mesh.py` 用纯标准库解析二进制/ASCII STL 与 OBJ，按有符号四面体分解算：

- 体积、表面积、包围盒、质心；
- 密度 → 质量；
- 相对质心的完整惯量张量（含惯性积）；
- 是否封闭（边界边比例）。

### 数值验证（与解析解对比，已写进测试）

| 形状 | 体积 | Ixx | Iyy | Izz |
|---|---|---|---|---|
| 1×1×1 立方体 | 1.000000（解析 1） | 0.166667（解析 1/6） | — | — |
| 2×1×3 长方体 | 6.000（解析 6） | 5.0000（解析 5） | 6.5000（解析 6.5） | 2.5000（解析 2.5） |
| 64 边形近似圆柱 r=0.5 h=1 | 0.784137（解析 0.785398） | 0.114275 | — | 0.097860（解析 0.098017） |

误差全部来自多边形离散，符合预期。

### 实测

`mesh_bot.json` 声明 2.4 kg，网格 0.3×0.2×0.1 m @ 1200 kg/m³：

- **M07 HIGH**：网格反推 7.200 kg，与声明 2.400 kg 相差 200%，并给出"若要让两者一致，
  密度应当是 300 kg/m³"；
- **M07 MEDIUM**：偏航惯量 0.0780 vs 声明 0.0200。

## 6. 用仿真验证，而不是"看着像"

前向仿真把日志里的命令逐拍喂进去，模型包含：

- 轮速学（上面那个雅可比）+ 轮速上限；
- 一阶执行器滞后 τ 与传输延迟（样本队列）；
- 附着限制：车体速度的变化率不能超过 `μ·g`；
- 里程计模型：固件用**模型里写的**轮半径和轮距换算，所以"真值 vs 里程计"的差
  正好等于参数比。

对比实测后，两条路径给结论：

1. **直接比值**（高置信，不依赖拟合）：`r_true = r_used × (真值距离/里程计距离)`，
   `L_true = L_used / (真值转角/里程计转角)`；
2. **数值灵敏度**（仅在仿真明显对不上时启用）：逐参数扰动 2%，算偏导，只保留
   "单独调整就能解释偏差、且幅度在 2%–40%" 的参数；多于一个就判无法辨识，不给单一根因。

### 实测

| 输入 | 结论 |
|---|---|
| 直线日志 + `--used-radius 0.05` | M09 一致（位移差 0.03%）；M10 轮半径应为 **0.0508 m** |
| 转向日志 + `--used-track 0.30` | M09 一致（转角差 0.21%）；M10 轮距应为 **0.32 m** |
| 麦轮日志（无 roll 的模型） | M09 不符 100%，且不给 M10——因为没有任何单个参数能解释，工具如实说"解释不了" |

## 7. Web App（零依赖）

~~~bash
python scripts/audit.py app --port 8765
# 或双击 run-app.cmd / 执行 ./run-app.sh
~~~

- 终端打印带一次性 token 的地址，浏览器打开即可；
- 拖入模型 / 日志 / 网格 / 实测参数，填命令的 vx、vy、ω 与固件轮半径轮距，点"运行诊断"；
- 右侧显示分级结论、证据（文件行号 + 原文）、建议修改，并可下载 report.md / findings.json / trace；
- **安全边界**：只绑 127.0.0.1、校验 token、上传限定扩展名与 8 MB、文件名强制 basename、
  不执行上传内容里的任何东西、不联网。

## 8. 边界（写清楚，不夸大）

1. **这是运动学 + 准静态动力学，不是接触动力学**。没有 MuJoCo/PyBullet 级别的接触求解，
   不预测振动、跳齿、翻车、轮胎非线性；需要这些请用真正的物理引擎。
2. 网格惯量假设网格是封闭、法向朝外的实体；不封闭会给出警告并可能偏小。
3. 滑移转向按"普通轮不可侧滑"的保守模型处理，只给出打滑倾向，不建轮胎模型。
4. 参数反推只覆盖轮半径、轮距、延迟三者在当前命令下的可辨识性；不可辨识时明确拒绝下结论。
5. 仍未在装有 ROS 2 的 Linux 环境实测（工具不依赖 ROS 运行时，只解析文件与日志）。
