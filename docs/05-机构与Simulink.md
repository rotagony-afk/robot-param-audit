# 机械臂 / 螺旋桨 / 激光雷达 与 Simulink 导出

> 第三阶段扩展：把"验证"从轮式底盘推广到三类完全不同的机构，并且能按诊断结果导出一份
> 可在 MATLAB 里一键生成 .slx 的 Simulink 模型包。所有数字来自本仓库代码的真实运行。

---

## 1. 为什么是这三类

轮式底盘验证的是"力与摩擦"；机械臂验证的是"几何与力矩"；螺旋桨验证的是"气动近似"；
激光雷达验证的是"扫描几何"。它们共用同一套思路：

> 把规格里写的数，和物理公式算出来的数，摆在一起比。

差别只在于公式。所以工具里是一个**机构目录**：每类机构一个模型、一族规则，接口统一。

## 2. 机械臂

### 模型

JSON 规格里的 `arm.joints` ，每个关节给出：

| 字段 | 含义 | 单位 |
|---|---|---|
| origin.xyz | 关节在父坐标系里的位置 | m |
| origin.rpy | 关节坐标系姿态 | 度 |
| axis | 转轴（或直线运动方向） | 单位向量 |
| limits | 关节行程 | 度（直线关节用 m） |
| effort | 额定力矩 | N·m |
| velocity | 额定角速度 | 度/秒 |

工具做四件事：

1. **正运动学**：连乘 Trans(origin) · R(rpy) · Rot(axis, q) 得到末端位姿；
2. **几何雅可比**：J_v = z_i × (p_tip − p_i)，J_w = z_i；
3. **逆解**：阻尼最小二乘，带关节限位裁剪；
4. **静力矩**：tau = J_v^T · F，F 是负载重力。

### 数值验证（已写进测试）

6 自由度示例 arm6.json：

| 检查 | 结果 |
|---|---|
| 零位末端位置 | (0.71, 0, 0.31) m，与连杆长度手算一致 |
| 雅可比 vs 有限差分（q 非零） | 最大偏差 **3e-7** |
| 可达点逆解残差 | 0.05–0.07 mm |
| 不可达点（1.4, 0, 1.4） | 残差 **370 mm** → A01 |
| 2 kg 负载静力矩 | 肩 10.68、肘 5.06、腕 1.94 N·m |

### 规则与实测

参数 `--target 0.45,0,0.30 --payload 2.0` （可达，残差 0.0 mm）时：

~~~text
[高] A03 [HIGH/已确认] 负载 2.00 kg 时关节力矩超限（j5_pitch）
     只算重力静载，需要的关节力矩就已经超过额定：j5_pitch 需要 1.94 N·m / 额定 1.50 N·m
~~~

参数 `--target 1.4,0,1.4` 时 → **A01 目标点不可达（末端残差 792.2 mm）**。

## 3. 螺旋桨

### 模型

执行盘动量理论的系数形式：

~~~
T = kT * omega^2      Q = kQ * omega^2      P = Q * omega
omega = rpm * 2*pi / 60
~~~

需要的输入：kT（N/(rad/s)^2）、kQ、max_rpm、单桨直径、桨数、电机扭矩上限、整机质量。

### 规则与实测

quad_x.json（kT=1.2e-5、9000 rpm、声明单桨 14 N）：

~~~text
T = 1.2e-5 * (942.5)^2 = 10.66 N      Q = 2.0e-7 * (942.5)^2 = 0.1777 N·m
P = 167.4 W      悬停转速 ≈ 5287 rpm      桨盘载荷 ≈ 210 N/m²

[高] P01 [HIGH/已确认] 声明最大推力 14.00 N 与 kT/转速算出的 10.66 N 相差 24%
~~~

P02（扭矩超限）、P03（推重比 < 1）、P04（桨盘载荷 > 400 N/m²）各有独立测试。

## 4. 激光雷达

### 模型

~~~
点数/秒 = (水平视场 / 角分辨率) * 垂直线数 * 帧率
光斑直径 = 2 * 距离 * tan(发散角/2)
盲区半径 = 安装高度 / tan(最低光束与水平面夹角)
~~~

### 规则与实测

lidar360.json（360° / 0.2° / 16 线 / 10 Hz，声明 10 万点/秒，装在 0.4 m 高）：

~~~text
实际点数 = (360/0.2) * 16 * 10 = 288,000 点/秒
盲区半径 = 0.4 / tan(15°) = 1.49 m

[高] L01 [HIGH/已确认] 声明 100000 点/秒与实际扫描几何不符（应为 288000）
[中] L02 [MEDIUM/已确认] 安装高度 0.40 m 时地面盲区半径 1.49 m
~~~

## 5. Simulink 导出

~~~bash
python scripts/audit.py model --model examples/mechanisms/arm6.json \
    --payload 2.0 --target 0.45,0,0.30 --simulink out/simulink
~~~

输出目录：

| 文件 | 内容 |
|---|---|
| build_rsw_NAME.m | MATLAB 函数：new_system → add_block × N → add_line × M → save_system |
| rsw_NAME.mdl | 同一模型的文本格式（Model { System { Block {...} Line {...} } }） |
| params.m | 全部数值变量 + 审计建议的修改（注释形式） |
| README.txt | 结构说明、离线自检结果、能力边界 |

### 三种被控对象

| 对象 | 模型结构 |
|---|---|
| 轮式底盘 | Step(速度指令) → Sum(+-) → Gain(1/tau) → Integrator(v) → Integrator(x) → Gain(r_used/r_true) → Scope |
| 机械臂 | 每关节：Step(力矩) → Sum(+-) → Gain(1/J) → Integrator(w) → Integrator(q) → Saturation(限位) → Scope；w 经 Gain(b) 反馈阻尼 |
| 螺旋桨 | Step(rpm) → Gain(2*pi/60) → Sum(+-) → Gain(1/tau_rotor) → Integrator(w) → Fcn(kT*u^2) → Scope |

### 离线结构自检

**验证状态（2026-10 实测）**：在 MATLAB R2025b + Simulink 上执行 build_rsw_arm6，成功生成并保存
rsw_arm6.slx（48 个模块 / 48 条连线），模型图正确渲染。本项目构建环境无法启动 MATLAB
（matlab -batch 报 System Error: File system inconsistency，与浏览器被沙箱拦截同因），
所以自动化只能做到「离线结构自检」。生成器把自检结果写进 README.txt：

- 模块名唯一；
- 每条连线的起点/终点都存在；
- 端口号 >= 1；
- 除源模块外每个模块都有输入连线；
- 模块类型在已知库路径表内。

自检通过时 README 写「通过（模块名唯一、连线无悬空、端口合法）」。

### 在 App 里直接跑

Web App 里勾选「同时导出 Simulink 模型包」，诊断结果下方会多出一块 Simulink 面板：

- 列出生成的文件，可直接下载；
- 「用本机 MATLAB 构建并运行」按钮：调用本机 matlab -batch，执行 build_rsw_*.m 并立刻 sim，
  把记录信号（To Workspace）的末值回显，例如机械臂的 6 个关节角。

前提是这台机器装了 MATLAB（没装会明确提示找不到 matlab.exe）。工具只允许运行自己生成的
build_rsw_*.m，不接受任意脚本路径。

### 你的用法

~~~matlab
cd <解压目录>
build_rsw_arm6
% 已生成: ...\rsw_arm6.slx
% 模块数: 48, 连线数: 48
~~~

然后在 MATLAB 里打开生成的 .slx 点 Run，在 6 个 Scope 里看关节角响应，
以及 Saturation 是否触发（触发就是撞限位）。

## 6. 边界（写清楚）

1. 机械臂是**静力学 + 运动学**：算可达性、奇异、静力矩；不算动力学（惯量耦合、科氏力）与柔顺控制。
2. 螺旋桨是**执行盘系数模型**：不算桨叶几何、雷诺数、前后飞干扰、地面效应。
3. 激光雷达是**扫描几何**：不算反射率、多回波、雨雾衰减、运动畸变。
4. Simulink 模型是**参数级验证模型**，不是接触动力学；.slx 需在你的 MATLAB 里生成。
