把 `submission/project-source.zip` 解压到一个**不含中文和空格**的路径，例如 `D:\rsw-audit\`。

~~~powershell
cd <解压后的目录>

~~~

期望最后一行是 `91 passed`。再随便跑一条，确认能出报告：

## 第 2 步：在 MATLAB 里验证 Simulink（15 分钟，**唯一需要你回我结果的一步**）

我已经把三份模型包预先生成好放进仓库了，你不用先跑诊断：

| 目录 | 被控对象 | 在 MATLAB 里执行 |
|---|---|---|
| `examples/mechanisms/simulink-arm/` | 6 轴机械臂（每关节二阶伺服 + 限位饱和） | `build_rsw_arm6` |
| `examples/mechanisms/simulink-quad/` | 四旋翼（转速滞后 + T=kT·ω²） | `build_rsw_quad_x` |
| `examples/demo_robot/simulink/` | 差速底盘（一阶速度环 + 里程计增益） | `build_rsw_demo_robot` |

操作：

~~~matlab
cd('<解压目录>\examples\mechanisms\simulink-arm')

~~~

正常会打印：

~~~text

模块数: 48, 连线数: 48
~~~

然后 Simulink 会打开模型，点 **Run**，在 6 个 Scope 里看关节角响应；Saturation 触发就是撞限位。

**这一步的目的**：你已经在 2026-10 用 MATLAB R2025b 跑通了（输出 已生成: ...rsw_arm6.slx /
模块数: 48, 连线数: 48），所以这一步**已完成**。剩下的可选项是点一次 **Run**，确认
6 个 Scope 里关节角按预期变化、sat_* 没有意外触发——把波形截图发我即可。

- ✅ 成功：截图或回我一句"能开、能跑"即可；
- ❌ 失败：把 MATLAB 命令窗口里的红字**整段**发我（尤其是 `add_block` 之类的行），我按你的版本改库路径或参数名。

## 第 3 步：建仓库并推送（10 分钟）

**先在 GitHub 网页建一个空仓库**：名字 robot-param-audit，**不要**勾 README / .gitignore / License
（License 已经有 LICENSE 文件了，勾了会冲突）。

### 最省事：用脚本（推荐）

工程目录里有一个 push-to-github.cmd，在 cmd 里运行：

~~~cmd
cd /d D:\Deepseek\Atom\robot-param-audit
push-to-github.cmd 你的账号
~~~

它会自动：用你的账号配好本仓库身份 → 提交 → 建 main 分支 → 设 remote → 推送。
（账号不要带尖括号。首次推送会弹 GitHub 登录窗，或被要求输入用户名 + Personal Access Token。）

### 或者手动八条命令

⚠️ 两个坑，都是踩过的：
1. **必须把「你的账号」换成真实账号，并去掉尖括号**。PowerShell 会把尖括号当重定向符，
   于是报"系统找不到指定的文件"。
2. **必须先提交，再推**。没有提交时 git push 会说 src refspec main does not match any。

~~~powershell
cd D:\Deepseek\Atom\robot-param-audit
git config user.name  "你的账号"
git config user.email "你的账号@users.noreply.github.com"
git add -A
git commit -m "rsw-audit: robot parameter and model verifier (42 rules, 91 tests)"
git branch -M main
git remote add origin "https://github.com/你的账号/robot-param-audit.git"
git push -u origin main
~~~

成功后打开 https://github.com/你的账号/robot-param-audit 确认能看到 README.md、
ros2-sim-hw-mismatch-auditor/、examples/、docs/。
